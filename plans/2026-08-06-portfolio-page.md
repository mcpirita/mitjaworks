## Зачем

Сайт — узкая посадочная под агентства недвижимости Таллина: ссылка, которую Дмитрий
отправляет сам. Но работ у него шире — живые сайты, видеомонтаж, съёмка других жанров.
Одна страница не обслуживает обе аудитории: агентству нужен специалист по недвижимости,
клиенту на сайт или монтаж — доказательство в совсем другой области.

Разделяем по аудиториям, не по разделам:

- `/` — остаётся ровно тем, чем есть. Недвижимость, архитектура, дрон. По смыслу не меняется.
- `/portfolio` — вторая посадочная под всё остальное. Отдельная ссылка для другой аудитории.

**Ключевое ограничение позиционирования:** ссылка на `/portfolio` идёт **только в подвал
главной**, не в pill-навигацию. Агентство, увидев «Web / Video» рядом с «Work / Aerial»,
считывает универсала вместо специалиста.

## Фаза 2 — Каркас

### Навигация — переделать до появления второй страницы

`src/components/SiteNav.tsx` держит ссылки хардкодом (`#work`, `#aerial`, …), бренд ведёт
на `#top`. На `/portfolio` эти якоря укажут в пустоту.

Перевести на пропсы: `links`, `brandHref`, `contactHref`. Каждая страница передаёт свой набор.
Без JS, как сейчас. На `/portfolio` бренд ведёт на `/` — заодно естественный путь обратно
к недвижимости.

### Контент

`export const portfolio = { … }` в `src/content/en.ts`, рядом с `site`. Один файл на язык
сохраняется — инвариант из шапки файла не ломается, эстонский `et.ts` добавляется той же
формой. Если файл станет неудобным, позже разложить в папку `src/content/en/`.

Тип по образцу существующих `Frame` / `WorkItem`:

```ts
export type PortfolioItem = {
  slug: string;
  name: string;
  discipline: "web" | "video" | "photo";
  year: string;
  role: string;        // что именно делал
  href?: string;       // живой сайт или ролик
  frames: Frame[];
};
```

### Страница

`src/app/portfolio/page.tsx` — статическая, со своим `export const metadata`.

Порядок секций:

1. Короткий интро-блок — кто это и что здесь. 2–3 строки, без биографии.
2. **Web** — карточки: скриншот, название, год, роль, ссылка на живой сайт.
3. **Video** — постер + подпись + ссылка наружу.
4. **Photography** — компактно: карточка «Commercial real estate & aerial», ведущая на `/`,
   плюс кадры других жанров. Важно: без фотографии страница читается как «объедки,
   что не влезло на главную».
5. **Contact** — переиспользовать `ContactSection`.

## Проверка вручную

1. `find .next/cache/images public -name "._*" -delete` перед любой локальной проверкой —
   иначе картинки отрендерятся битыми. Это не баг сайта, а AppleDouble-сайдкары на exFAT.
2. `npm run build && npm run lint` — обе чистые.
3. `npm run dev`, открыть `/` и `/portfolio`:
   - на `/` pill-навигация ведёт по секциям как раньше, в подвале появилась ссылка на `/portfolio`;
   - на `/portfolio` бренд ведёт на `/`, ссылки на живые сайты открываются в новой вкладке;
   - карточка Photography ведёт обратно на `/`.
4. Мобильная вёрстка — через страницу-обёртку с `<iframe width="390">`. Напрямую
   `--window-size=390` в headless Chrome на macOS не сжимается ниже ~404px и даёт ложное переполнение.
5. Перед публикацией сверить фактуру: каждое название заказчика и каждый год подтверждены
   Дмитрием, ничего не выведено по догадке.
