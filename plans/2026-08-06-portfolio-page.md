## Зачем

У страницы две функции, и обе одинаково важны:

1. **Библиотека работ.** Сейчас работы Дмитрия размазаны по папкам на диске и по гугл-драйву.
   Одно место, где всё лежит в показываемом виде, нужно ему самому.
2. **Ссылка, которую он отправляет.** Не только клиентам, но и работодателям — если он пишет
   по вакансии на веб-разработку или на монтаж, портфолио должно уже существовать, а не
   собираться в спешке.

Аудитории разные, поэтому и посадочные разные:

- `/` — остаётся ровно тем, чем есть. Недвижимость, архитектура, дрон. Для агентств Таллина.
- `/portfolio` — веб-разработка, видеомонтаж, съёмка других жанров. Для работодателей и клиентов
  на сайты и монтаж.

**Ключевое ограничение позиционирования:** ссылка на `/portfolio` идёт **только в подвал
главной**, не в pill-навигацию. Агентство, увидев «Web / Video» рядом с «Work / Aerial»,
считывает универсала вместо специалиста.

**Страница живёт и меняется.** Работы будут добавляться и убираться — контент лежит данными
в `src/content/en.ts`, добавление работы не должно требовать правки вёрстки.

## Зафиксированные решения

| Вопрос | Решение |
|---|---|
| Роут | `/portfolio` — одна страница с секциями |
| Видимость с главной | Только строка в подвале, рядом с копирайтом |
| Разделение на `/web` и `/video` | Не сейчас. Когда веб перевалит за ~6 работ — вынести в свой роут |
| Что показываем | Веб-разработка · видеомонтаж · съёмка других жанров |
| Тон и оформление | Та же типографика, палитра, сдержанность. Отдельного визуального языка не заводим |
| Как показываем **сайты** | Скриншот десктопа 1440 в `PhotoPlate` + ссылка на живой сайт |
| Как показываем **приложения** | Скриншот + немой скринкаст 25–40 сек. Живая демка — только Штабу |
| Имена клиентов | Называть можно (решение Дмитрия 2026-08-19). Персональные данные внутри приложений — нельзя |
| Красные линии | Те же, что в `CLAUDE.md`: не выдумывать заказчиков, отзывы, статистику; не заявлять того, чего не делал |

### Почему приложениям нужен скринкаст, а не скриншот

У таск-менеджера, CRM и дашборда продающее — не картинка, а то, что вещь работает. Скриншот
доски задач читается как макет; те же двадцать секунд с живым перетаскиванием читаются как
готовый продукт. Записывает Дмитрий (`Cmd+Shift+5`, запись окна), пережимает и встраивает агент.
Вес: ~30 сек интерфейса при 1440 ≈ 2–3 МБ, интерфейс жмётся куда лучше дрон-видео.

### Почему живая демка только Штабу

Демо-инстанс — отдельный проект на Vercel, отдельная база с выдуманными данными, режим только
для чтения. Это 2–3 часа на первый и постоянный присмотр: база протухает, ссылка в портфолио
остаётся. Штаб уже задеплоен (`shtab-nu.vercel.app`) — ему нужен только сид фейковых задач и
отдельный ключ доступа, поэтому цена приемлемая. Дашборд инвестиций — кандидат номер два, когда
появится.

### Данные в скринкастах и демо — только выдуманные

В кадре не должно быть ни одной настоящей задачи, цели, заметки, клиента, суммы или даты.
Ни в Штабе, ни в CRM, ни в Arina, ни в дашборде инвестиций. Причины две:

1. **Приватность.** Штаб — личные дела Дмитрия, CRM и Arina — чужие люди с контактами и
   деньгами. Публичная ссылка расходится навсегда и попадает не только тем, кому её отправляли.
2. **Презентация.** Реальные данные выглядят неопрятно — просроченные задачи, пустые описания,
   заметки в одно слово. Это читается как бардак, а не как система. Выдуманный набор собирается
   так, чтобы показать сильные места приложения: фильтры, статусы, повторяющиеся задачи, отчёт.

Порядок работы: отдельная база + сид-скрипт с выдуманными данными → приложение поднимается
локально на ней → запись идёт только с неё. Продакшен-инстанс в кадре не участвует.
Сид-набор генерирует агент, Дмитрий подтверждает правдоподобность.

**Что утекает мимо приложения** — проверить до записи:

- [ ] Чистый профиль браузера или инкогнито — без вкладок и панели закладок
- [ ] «Не беспокоить» включён — уведомления в кадр не лезут
- [ ] Запись окна (`Cmd+Shift+5` → выбранное окно), а не всего экрана — иначе в кадре
      верхняя строка macOS с именем и календарём
- [ ] Автозаполнение в полях и заголовок окна не выдают настоящих данных
- [ ] Готовую запись просмотреть покадрово перед публикацией

### Красная линия по данным

`Project Arina` — инструмент реального клиента с персональными данными немецких арендаторов.
Живой публичной ссылки не будет ни при каких условиях; скриншоты и скринкаст — только с
выдуманными данными. То же правило для CRM, если там заведены настоящие клиенты.

Решает видео: если по нему наберётся две работы и обе слабые, хаб покажет пустой раздел.

**Что будет стоить переезд, если выберем хаб:**

- `title`/`description` из `src/app/layout.tsx` уехать в `metadata` страницы раздела;

Переезд переживают: все секции, объект `portfolio`, `Shell`, `PhotoPlate`, `ContactSection`,
`SiteNav` (уже на пропсах). Выбрасывается композиция страницы и интро-блок. Старая ссылка

На `/portfolio` бренд ведёт на `/` — заодно естественный путь обратно к недвижимости.

### Контент

`export const portfolio = { … }` в `src/content/en.ts`, рядом с `site`. Один файл на язык
сохраняется — эстонский `et.ts` добавляется той же формой.

Тип по образцу существующих `Frame` / `WorkItem`:

```ts
export type PortfolioItem = {
  slug: string;
  name: string;
  discipline: "web" | "video" | "photo";
  year: string;
  role: string;         // что именно делал
  stack?: string;       // одной строкой, только для web
  href?: string;        // живой сайт или ролик; может не быть — см. Arina
  clip?: {              // скринкаст, если есть
    src: string;
    poster: string;
  };
  frames: Frame[];
};
```

Добавление работы = одна запись в массиве. Вёрстка не трогается — это требование, а не пожелание:
страница будет меняться постоянно.

## Проверка вручную

1. `find .next/cache/images public -name "._*" -delete` перед любой локальной проверкой —
   иначе картинки отрендерятся битыми. Это не баг сайта, а AppleDouble-сайдкары на exFAT.
2. `npm run build && npm run lint` — обе чистые.
3. `npm run dev`, открыть `/` и `/portfolio`:
   - на `/` pill-навигация ведёт по секциям как раньше, в подвале появилась ссылка на `/portfolio`;
   - на `/portfolio` бренд ведёт на `/`, ссылки на живые сайты открываются в новой вкладке;
   - карточка Photography ведёт обратно на `/`;
   - скринкасты не грузятся до клика (`preload="none"`), постеры на месте.
4. Мобильная вёрстка — через страницу-обёртку с `<iframe width="390">`. Напрямую
   `--window-size=390` в headless Chrome на macOS не сжимается ниже ~404px и даёт ложное
   переполнение.
5. Перед публикацией сверить фактуру: каждое название заказчика, год и роль подтверждены
   Дмитрием, ничего не выведено по догадке. Отдельно — что все ролики в разделе Video сняты
   или смонтированы им, а не взяты из чужих материалов.
